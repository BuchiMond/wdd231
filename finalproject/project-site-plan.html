Site Name

Graphic Design Studio

This name was chosen because it clearly communicates the core service — professional graphic design — while "Studio" suggests a creative, collaborative workspace. It is easy to remember and applicable across branding, print, and digital design work.

Site Purpose

Graphic Design Studio is an online portfolio and service hub for a freelance graphic designer. The site showcases completed projects, describes available services (logo design, brand identity, social media graphics, and layout design), and provides a way for prospective clients to get in touch or submit a project brief.

Scenarios

Questions a typical site visitor might ask:

  • I need a new logo — can I see examples of past branding work and request a quote?
  • What design services are available, and how long does a typical project take?

Color Scheme

Typography

The site uses a single typeface: Rubik (Google Fonts). Different weights create hierarchy without needing multiple fonts.

  • Rubik 700 (Bold) — headings and the site name
  • Rubik 400 (Regular) — all body text and paragraphs
  • Rubik 500 (Medium) — navigation links
